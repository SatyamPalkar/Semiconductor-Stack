# Locally bundled type

- Barlow Regular and SemiBold: https://github.com/google/fonts/tree/main/ofl/barlow
- Barlow Condensed ExtraBold: https://github.com/google/fonts/tree/main/ofl/barlowcondensed

Original, unmodified TTF files downloaded from Google Fonts' official repository. The reading family's license is `OFL.txt`; the condensed family's license is `BarlowCondensed-OFL.txt`. Both use the SIL Open Font License 1.1. Next's local font loader serves the files from the application's own origin; visitors do not request fonts from Google.
