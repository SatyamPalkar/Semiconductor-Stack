# ADR 0001 — prove the research data path locally

Accepted for milestone 1. Use actual PostgreSQL/pgvector, Decimal calculations, recorded primary-source excerpts for CI, one pinned local embedding model and optional hosted generation. Keep the static research export independent of API availability. Use a separate native PostgreSQL cluster when Docker is absent; preserve the portable Compose path and disclose that Docker execution is unverified on this Mac.

The first source is NVIDIA's official FY2025 results. TSMC access failures remain visible as missing coverage. Fiscal starts not established by the selected source remain null. No guessed financial figures, synthetic investment findings, fake agent runs or unverifiable evaluation scores fill gaps.

LangGraph/checkpoint jobs and costed AWS stacks follow the verified local foundation. This avoids equating an infrastructure inventory with a functioning research system. No live-model billing or cloud provisioning is authorized by local implementation alone.
